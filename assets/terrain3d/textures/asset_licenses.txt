ambientCG textures
------------------
All ambientCG assets are provided under the
Creative Commons CC0 1.0 Universal License.
https://docs.ambientcg.com/license/

These two sets are byte-identical copies of the ones shipped in the
Terrain3D demo (demo/assets/textures/), repacked by Terrain3D as
<name>_alb_ht.png (albedo + height) and <name>_nrm_rgh.png (normal + roughness).

Grass (Terrain3D texture id 0):
  ground037_alb_ht.png, ground037_nrm_rgh.png
  https://ambientcg.com/view?id=Ground037

Cliff (id 1) and Seabed (id 3, the same set tinted and rescaled):
  rock023_alb_ht.png, rock023_nrm_rgh.png
  https://ambientcg.com/view?id=Rock023

Project-generated textures
--------------------------
Sand (id 2):
  sand_alb_ht.png, sand_nrm_rgh.png
  Generated procedurally (value noise, numpy) by tools/make_sand_texture.py,
  part of this project and covered by its LICENSE. Not made with an
  image-generation model. Re-running the script reproduces both files
  pixel for pixel (fixed seed).
