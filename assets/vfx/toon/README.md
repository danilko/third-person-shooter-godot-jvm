# The character toon look (PLAN.md 6.10)

Our own code, written for this project -- no third-party shader source is in this folder.

| file | what it is |
|---|---|
| `toon_params.json` | **THE one owner of the look's numbers.** Edit here, then run both generators. |
| `toon_params.gdshaderinc` | GENERATED by `tools/build_toon.py` (the Godot uniform defaults). Never hand-edit. |
| `toon_common.gdshaderinc` | the lighting: a ramp in `light()` over the engine's own lights |
| `toon_character.gdshader` | opaque surfaces (skin, clothes) |
| `toon_character_cutout.gdshader` | hair cards and lashes: double-sided, alpha-tested |
| `toon_nodes.blend` | GENERATED by `blender/tools/build_toon_nodegroup.py -- --library`: node group `OW_Toon`, the Blender preview of the same look (EEVEE) |
| `review/` | before/after renders (`tools/godot/shot_toon_character.gd`) and the two parity spheres |

**Not MToon.** A self-lit look stands unlit at night and unshadowed at noon. This one is a RAMP OVER THE
ENGINE'S LIGHTS: the sun and moon, the street-lamp pool and headlights all light a character, and it
receives and casts shadows. Three differences from PBR: the diffuse falls off in a band at
`shade_threshold` and the shade side keeps `shade_tint` of the light (the anime shadow colour); a
highlight band in the surface's own tone; a rim on silhouettes that face the light. The face mesh's normal
is pulled toward the head's forward (`face_flatten`), the cheap form of a Genshin-style face shadow.

**Using it:** `Character.toonLook = true` (off by default -- whether the game ships in this look is
PLAN.md 3.14's decision). `character.ToonLook` swaps each imported material for the toon one, ONE shared
material per source material across every character; the face direction is an `instance uniform`.

**Gate:** `tools/check_toon_parity.sh` -- one lit sphere rendered by Godot (xvfb) and by Blender (EEVEE,
headless) must both put the lit->shade edge at `shade_threshold`, keep it narrow and hold the shade side
at `shade_tint`'s luminance; a plain Lambert control must fail in both. Measured 2026-09-22: edge N.L
0.0796 in both (want 0.08), width 0.017 in both, shade/lit 0.628 / 0.622 (want 0.623).
